- Fixed user messages going missing from the context and from `on_user_turn_message_added` in realtime service mode when a user mute strategy (e.g. `AlwaysUserMuteStrategy`, `FunctionCallUserMuteStrategy`) muted the user before the service's transcript arrived. Realtime services often deliver the transcript after their reply has started; `LLMUserAggregator` now adds a transcription that arrives while the user is muted to the context, without passing it to the user turn strategies, so muting still blocks new user turns and interruptions.
